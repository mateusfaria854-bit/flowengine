# FlowEngine

[English](README.md) · [Licença AGPL-3.0-only](LICENSE)

**Crie fluxos. Conecte sistemas. Automatize processos.**

FlowEngine é uma plataforma de automação de código aberto em desenvolvimento, com editor visual, motor de execução orientado a eventos, processamento assíncrono e integrações extensíveis.

> **Estado atual:** planejamento e documentação. Ainda não existe um aplicativo executável, demonstração hospedada ou serviço comercial.

## Funcionalidades planejadas

- Editor visual de workflows.
- Gatilhos manuais, agendados e por webhook.
- Requisições HTTP, transformação de dados e condicionais.
- Filas, histórico de execução e novas tentativas controladas.
- Organizações, isolamento de dados e credenciais criptografadas.

## Modelo de produto

- **Community:** versão open source para hospedagem própria.
- **Cloud:** proposta de serviço SaaS gerenciado por assinatura.
- **Enterprise:** possibilidade futura de licenciamento comercial alternativo, condicionada à análise jurídica e aos direitos necessários.

A proposta inicial é validar automações de planilhas e processos empresariais, usando dados fictícios nas demonstrações.
