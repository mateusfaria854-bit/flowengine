# Contributing to FlowEngine

FlowEngine is currently in its design stage. Contributions to architecture and scope are welcome.

- Open an issue to discuss substantial changes.
- Keep changes focused and use descriptive commit messages.
- Add tests when introducing executable behavior.
- Document new configuration, contracts and limitations.
- Do not commit credentials, real workplace records or generated dependencies.
- Update the roadmap only after acceptance criteria are verified.

The development commands and CI requirements will be added when the workspace is bootstrapped.
