# Contributing to FlowEngine

FlowEngine is currently in its design stage. Contributions to architecture and scope are welcome.

- Open an issue to discuss substantial changes.
- Keep changes focused and use descriptive commit messages.
- Add tests when introducing executable behavior.
- Document new configuration, contracts and limitations.
- Do not commit credentials, real workplace records or generated dependencies.
- Update the roadmap only after acceptance criteria are verified.

The development commands and CI requirements will be added when the workspace is bootstrapped.

## Licensing and contributions

New original project material is intended to be licensed under AGPL-3.0-only. Retain copyright and license notices, and disclose the origin and license of third-party material.

To preserve the possibility of future commercial alternative licensing, substantive external code and documentation contributions will not be merged until an appropriate contributor agreement has been reviewed, adopted and accepted by the relevant rights holders. No CLA is currently in force, and opening an issue or pull request does not by itself grant commercial relicensing rights.

Do not submit confidential or employer-owned material without authorization. See [licensing policy](docs/licensing.md).
